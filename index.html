comandos do git

  • git init - inicializa o repositório git
  • git add nomedoarquivo | . - adiciona item na stage
  • git status - exibe o estado atual dos arquivos (modificados, staged, etc)
  • git log - mostra o histórico detalhado de commits
  • git config --global user.name "Seu Nome" - define o nome que aparecerá nos commits
  • git config --global user.email "seuemail@exemplo.com" - define o e-mail vinculado aos commits
  • git config --list - lista todas as configurações do Git no sistema
  • git commit -m "mensagem" - grava as alterações da stage no histórico
  • git branch -M main - renomeia o branch principal para "main"
  • git switch -c - cria branch também
  • git switch nome-da-branch - muda de branch
  • git log --oneline - exibe o histórico de commits resumido em uma linha
  • git diff - mostra as alterações feitas nos arquivos que ainda não foram adicionadas
  • code ./ - abre a pasta do projeto no Visual Studio Code
  • git branch nome-do-branch - cria um novo branch (ramificação) para testar novas funcionalidades
  • git branch - lista os branches existentes (o que tiver um asterisco * é o atual)
  • git checkout nome-do-branch - muda para o branch especificado (ex: git checkout main)
  • git switch nome-do-branch - uma forma mais moderna de mudar entre branches
  • git log --all --oneline - mostra todos os commits de todos os branches de forma resumida
  • git log --all --graph - exibe o histórico de commits com uma representação visual das ramificações (linhas coloridas no terminal)
  • git log --all --oneline --graph - a combinação definitiva: histórico visual, resumido e completo
  • Ctrl + C - comando do terminal para cancelar um comando travado ou interromper um processo (como você fez no git add ,)
  • git merge nome-do-branch - junta as alterações do branch especificado no seu branch atual
  • Ctrl + L - limpa a tela do terminal para organizar a visualização
  • git branch -m novo-nome - altera o nome do branch atual
  • git branch -m nome-antigo novo-nome - altera o nome de um branch específico
  • git branch -d nome-do-branch - apaga um branch que já foi mesclado (merge)
  • git branch -D nome-do-branch - apaga um branch à força (mesmo que não tenha sido mesclado)
  • git remote add origin https://github.com/usuario/nomedorepositoriogithub.git - Conecta ao repositório remoto
  • git push -u origin main - Envia seus commits locais para o servidor
  • git push --set-upstream origin nome-da-new-branch - puchaa para nova branch
  • git pull - Traz e mescla as novidades do servidor para sua máquina
